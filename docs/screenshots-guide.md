# VoiceGym — Store Screenshots Guide

## Required Screenshots

### Google Play Store
- Minimum 2, maximum 8 screenshots
- Size: 1080 x 1920px (portrait) or 1920 x 1080px (landscape)
- Format: JPG or PNG
- No alpha/transparency

### Apple App Store
- Required for each device size you support
- iPhone 6.9" (iPhone 16 Pro Max): 1320 x 2868px
- iPhone 6.7" (iPhone 14 Plus): 1284 x 2778px
- At least 1 set required

## How to Take Screenshots

### Android (Google Play)
1. Run app on your phone via Vercel URL
2. Navigate to each screen
3. Take screenshot with Volume Down + Power button
4. Resize to 1080x1920 using any image editor

### iOS (App Store)
- Requires Mac with Xcode and iOS Simulator
- Or use your iPhone and resize screenshots
